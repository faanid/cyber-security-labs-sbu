# Lab 02 — Biometric Sensitivity and Specificity

**Status:** Planned  
**Classification:** Independent practical lab  
**Related homework:** Question 2

## Objective

Use a synthetic dataset to explore sensitivity, specificity, false acceptance, and false rejection as a decision threshold changes.

## Planned experiments

- Generate or define fictional genuine-user and impostor scores.
- Apply multiple thresholds.
- Calculate true positives, true negatives, false positives, and false negatives.
- Present a confusion matrix and discuss the security/usability trade-off.

## Security notes

Use synthetic data only. This lab does not evaluate a real biometric product or make claims about actual biometric accuracy.
