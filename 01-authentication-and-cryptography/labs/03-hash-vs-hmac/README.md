# Lab 03 — Hash Functions vs. HMAC

**Status:** Planned  
**Classification:** Independent practical lab  
**Related homework:** Question 3

## Objective

Demonstrate the difference between an unkeyed cryptographic hash and a keyed message authentication code.

## Planned experiments

- Calculate a SHA-256 digest for a sample message.
- Generate an HMAC using a secret key.
- Modify the message and verify that validation fails.
- Explain why a public hash alone does not prove who created a message.

## Security notes

Use fictional messages and development-only keys. Never commit real secrets. Use constant-time comparison APIs where applicable.
