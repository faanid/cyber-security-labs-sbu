# Lab 06 — Symmetric vs. Asymmetric Encryption

**Status:** Planned  
**Classification:** Independent practical lab  
**Related homework:** Question 6

## Objective

Compare symmetric and asymmetric cryptography through small, reproducible encryption and decryption experiments.

## Planned experiments

- Encrypt and decrypt sample data with authenticated symmetric encryption (for example, AES-256-GCM).
- Generate an asymmetric key pair and demonstrate a suitable public-key operation.
- Compare key management, performance considerations, and use cases.
- Explain how hybrid encryption combines the strengths of both approaches.

## Security notes

Use generated development keys and fictional data. Do not commit private keys. Do not invent benchmark conclusions: record the environment, method, and limitations if measuring performance.
