# Practical Labs

These labs are independent practical explorations of concepts related to the course. Clearly label any work that was not assigned by the instructor.

| Lab | Topic | Suggested implementation |
|---|---|---|
| [01 — Password Salting](01-password-salting/) | Password hashing, salts, precomputation | Node.js |
| [02 — Biometric Metrics](02-biometric-metrics/) | Sensitivity, specificity, false positives/negatives | JavaScript or Python |
| [03 — Hash vs. HMAC](03-hash-vs-hmac/) | Integrity and message authentication | Node.js |
| [04 — Diffie–Hellman and MITM](04-diffie-hellman-mitm/) | Key exchange and authenticated identity | Node.js |
| [05 — MFA Design](05-mfa-design/) | Authentication factors and login flows | Node.js |
| [06 — Symmetric vs. Asymmetric](06-symmetric-vs-asymmetric/) | AES-GCM, public/private keys, hybrid encryption | Node.js |

## Lab quality checklist

- [ ] State whether the lab is coursework or independent practice.
- [ ] Explain the security concept in your own words.
- [ ] Include setup and run instructions.
- [ ] Include tests or reproducible steps.
- [ ] Explain the observed results.
- [ ] Include defensive takeaways and references.
- [ ] Remove secrets and personal data before committing.
