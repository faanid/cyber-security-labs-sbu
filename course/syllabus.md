Course Syllabus – Cybersecurity

Institution: Shahid Beheshti University (SBU)
Course: Cybersecurity
Focus: Security Fundamentals, Authentication, Cryptography, Operating Systems, and Network Security

1. Course Overview

This course introduces fundamental cybersecurity concepts and explores common security mechanisms, threats, and defensive techniques across software systems, operating systems, and computer networks.

The course covers authentication, cryptography, internet security, operating system security, and network threats, providing a foundation for understanding security risks and the principles used to protect digital systems.

2. Course Topics

01. Introduction to Cybersecurity

- Fundamental cybersecurity concepts
- Security principles and terminology
- Overview of common security challenges

02. Authentication and Cryptography

Authentication

- Authentication mechanisms
- Password-based authentication
- Authentication tools and techniques

Cryptography

- Cryptographic fundamentals
- Hash functions
- Symmetric and asymmetric encryption
- Cryptographic tools and applications

03. Security Programs and Tools

- Introduction to security-related software and tools
- Overview of tools used in cybersecurity

04. Internet and User-Side Security

- Internet security fundamentals
- Security risks associated with internet usage
- User-side security considerations

05. Operating System Security

- Operating system security fundamentals
- Common operating system security concerns
- Security mechanisms and protection concepts

06. Network Security

Network Threats

- Common network attacks and threats

Wireless Network Security

- Wireless network security concepts
- Wireless communication threats

Denial-of-Service (DoS)

- DoS attack fundamentals
- Network availability and service disruption

Transport Layer Security (TLS)

- Secure communication
- TLS fundamentals and encrypted connections

Virtual Private Networks (VPN)

- VPN concepts and applications
- Secure network communication

Firewalls

- Firewall fundamentals
- Network traffic filtering and access control

3. Learning Objectives

By studying these topics, students develop a foundational understanding of:

- Core cybersecurity concepts and security terminology.
- Authentication methods and password security.
- Cryptographic techniques and their role in protecting information.
- Common internet, operating system, and network security threats.
- Secure communication protocols such as TLS and VPN technologies.
- Network protection mechanisms, including firewalls.
- The relationship between security principles and software systems.

4. Practical Learning

This repository complements the course material with personal notes, written assignments, and practical exercises.

The practical section focuses on exploring security concepts through controlled experiments and documenting:

- How security mechanisms work.
- How common vulnerabilities and attacks occur.
- What risks they introduce.
- Which defensive techniques can reduce those risks.
