# Learning Resources

This directory contains supplementary materials and references related to the cybersecurity course.

## Contents

Course resource files are currently stored directly in this directory. The files have not yet been reorganized into separate subdirectories.

For clarity, future resources can be grouped into:

- `lecture-notes/` — original notes and summaries written by the repository owner.
- `references/` — links to official documentation, technical articles, and external learning resources.

## Copyright and attribution

Third-party course slides, handouts, and PDFs remain the property of their respective authors or copyright holders. Uploading material for educational purposes does not automatically grant permission to redistribute it publicly.

Keep third-party materials in this public repository only when redistribution is permitted. Otherwise, remove the files from the public repository and provide your own notes, summaries, bibliographic details, or links to the original sources.

Do not include student IDs, private contact information, or other personal data in published materials.
